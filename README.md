# Тестовое задание: API-тестирование сервиса Restful-Booker

В рамках выполнения тестового задания проведено функциональное тестирование REST API сервиса.
Протестированы основные CRUD-эндпоинты, составлены тест-кейсы, выявлены дефекты, а также создана автоматизированная коллекция в Postman.

## Структура репозитория

В корне проекта находятся следующие артефакты:

- **`YASP.postman_collection.json`** — экспортированная коллекция Postman. Содержит все запросы к API с настроенными проверками во вкладке `Tests`. Позволяет запускать позитивные и негативные сценарии в автоматическом режиме.
- **`TestCases.xlsx`** — файл с тест-кейсами.
- **`BugReport.xlsx`** — баг-репорт. В файле описаны найденные дефекты в работе сервиса с указанием шагов воспроизведения, фактического и ожидаемого результатов.

## Запуск Postman коллекции

Для того чтобы выполнить проверки вручную или запустить коллекцию:

1. Скачайте и установите [Postman](https://www.postman.com/).
2. Нажмите кнопку **Import** в левом верхнем углу.
3. Загрузите файл `YASP.postman_collection.json`.
4. После импорта вы увидите коллекцию в левой панели.
5. Чтобы запустить все тесты сразу, нажмите на три точки (…) рядом с названием коллекции и выберите **Run collection**.
6. Все проверки (статус-коды, структура и значения JSON, время ответа) выполняются автоматически во вкладке `Tests`.

> **Примечание:** Для корректной работы цепочки запросов (например, создание бронирования через `POST /booking` с последующим получением ID для `PUT/DELETE`) переменные окружения не требуются — все необходимые данные передаются через переменные коллекции, настроенные внутри запросов.
